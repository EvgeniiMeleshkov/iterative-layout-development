# Iterative Layout Development

**Скилл для Claude Code: вёрстка по макету из Figma пиксель в пиксель.** Агент верстает страницу по одному блоку, а каждый блок сверяет с макетом *новый* агент — числами, а не на глаз — пока расхождений не останется. Потом следующий блок.

> Кодинг-агенты хорошо пишут логику и плохо верстают. Страница «вроде похожа», но отступ уехал на 6px, размытие за фото пропало, шрифт — фолбэк, иконка сплющена. В итоге CSS правится руками.

Скилл это лечит. По нему сделаны настоящие страницы в проде, где каждый блок закрыт вердиктом «СОВПАДАЕТ».

[English version](README.md)

## Почему агенты плохо верстают

Не потому, что не умеют CSS. Потому что **проверяют себя сами, глядя на скриншот.** Автор видит то, что хотел сделать, а не то, что отрисовалось. А скриншот прячет ровно то, из-за чего макет выглядит правильно: 2px отступа, полупрозрачную подложку, не чёрную тень, анимацию при наведении.

Поэтому самопроверки здесь нет:

- **Исполнитель не судит свой блок.** Каждый раунд сверяет новый агент с чистым контекстом. Он не видит отчёт исполнителя, дифф и прошлые починки — только макет и рендер.
- **Проверяющий сравнивает числа:** значения Figma против вычисленных стилей браузера и координат элементов от корня блока. Скриншоты — третий слой, для наложений и обрезки.
- **Круг идёт до вердикта «СОВПАДАЕТ».** «Почти так же» — не совпало.

## Установка

```bash
git clone https://github.com/EvgeniiMeleshkov/iterative-layout-development.git
cp -r iterative-layout-development/skills/iterative-layout-development ~/.claude/skills/
```

Основной `SKILL.md` — на английском. Русский оригинал лежит в [`translations/ru/SKILL.md`](translations/ru/SKILL.md): чтобы пользоваться им, скопируйте его вместо английского в папку скилла.

## Запуск

Фразой в сессии Claude Code: «работаем по iterative layout development, делаем одну страницу <название>» / «…делаем всё» / «…делаем блок X», или командой `/iterative-layout-development`.

## Что нужно

Claude Code с субагентами · Figma-десктоп с включённым MCP-сервером (работаем с копией макета в своих черновиках) · браузерный инструмент для агента (Claude in Chrome, Playwright MCP) · запущенный dev-сервер · Python 3 для клиента Figma.

## Цена и когда не нужен

Это дорого: каждый раунд — новый агент со скриншотами, лимита раундов нет, страница из 15 блоков — десятки запусков. Окупается на посадочных и маркетинговых страницах, где важен пиксель. Для продуктового интерфейса на готовых компонентах — избыточен.
